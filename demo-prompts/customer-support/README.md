# 顧客サポート責任あるAIデモ用システムプロンプト

蒼空フロンティア株式会社の架空家電サポートを題材に、責任あるAIの8側面を一つずつ改善するための全文プロンプトである。
各ファイルは累積版であり、差分ではない。チャットをクリアしてから、ファイル全体を「システムプロンプト(ペルソナ)」へ貼り付ける。

ステージ5以降は「RAG（製品情報検索）」をオンにする。社内規定RAGとWeb検索はオフにする。
ステージ8では、同じ最終プロンプトを管理者の「アプリ既定プロンプト」へ移し、管理者必須Guardrailと監査を組み合わせる。

すべて教材用であり、実在する個人情報、製品、故障、修理受付には使用しない。
