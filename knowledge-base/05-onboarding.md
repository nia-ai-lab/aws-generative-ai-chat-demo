# AnyCompany 入社手続きガイド

> デモ用の架空文書です。実在の企業・制度とは関係ありません。

**第1条（目的）** このガイドは、新たに入社する社員の手続きと、入社後30日間の流れを定める。

**第2条（入社前の提出書類）** 入社日の2週間前までに、人事システムから雇用契約書、給与振込口座届、通勤経路届、マイナンバー届を提出する。入社日前3か月以内に受診した健康診断書も提出する。

**第3条（入社初日）** 入社初日は9時30分に本社受付へ来る。人事部のオリエンテーションで社員番号と社員証を受け取り、情報システム部から会社貸与端末を受け取って多要素認証を設定する。

**第4条（必須研修）** 入社後30日以内に、情報セキュリティ研修、ハラスメント防止研修、生成AI利用研修をeラーニングで修了する。

**第5条（試用期間）** 試用期間は入社日から3か月とする。試用期間中も年次有給休暇を取得でき、入社日に10日を付与する（就業規則第10条）。

**第6条（入社手続きの問い合わせ）** 入社手続きに関する問い合わせは、人事部の入社手続き担当（内線2120）が受け付ける。
