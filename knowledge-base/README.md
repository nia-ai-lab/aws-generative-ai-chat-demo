# RAGデモ用文書（AnyCompany 人事規程）

このフォルダの文書は、すべて架空の企業「AnyCompany」の架空の社内規程です。実在する企業・人物・制度とは関係ありません。教材（Generative AI Essentials on AWS）で一貫して扱う「AnyCompany 人事アシスタント」の根拠文書として使います。

| ファイル | 文書名 | 主なデモ |
|---|---|---|
| 01-work-rules.md | 就業規則 | 結婚休暇（第12条）、在宅勤務（第9条）、年次有給休暇（第10条・第11条） |
| 02-childcare-leave.md | 育児休業規程 | 「育休は何日取れる？」、申請先（第10条に担当者の携帯番号があり、PII匿名化の出力側デモに使う） |
| 03-benefits.md | 福利厚生規程 | 結婚祝金、人間ドック補助 |
| 04-evaluation-guide.md | 評価の手引き | 「評価はいつ？」、評価の公平性、他の社員の評価は回答しない |
| 05-onboarding.md | 入社手続きガイド | 「入社の手続きは？」 |
| 06-payroll.md | 給与規程 | 給与明細の公開日、給与の個別相談の窓口 |
| 07〜15 | ハラスメント防止、情報セキュリティ、生成AI利用、経費精算、出張、データ分類、事業継続、副業、端末管理 | 質問と関係する規程だけが検索されることの確認 |

デモの前提として、次の内容は意図的に**どの文書にも書いていない**。

- 在宅勤務手当（「在宅勤務手当はいくら？」で、根拠のない金額を作らないかを確認する。教材 M5 のグラウンディングの例）

文書を変更した場合は `amplify/custom/application-stack.ts` の `RAG_DOCUMENT_VERSION` を上げ、デプロイ時にナレッジベースを再同期する。人事ツール（`agent/hr_tools.py`）の残日数と申請チェックは就業規則第10条から第15条と一致させる。
